# Рендер мультика «Chill Client»

Всё генерируется кодом, без Blender и без внешних ассетов.

| файл | что делает |
|---|---|
| `mc3d.py` | софтверный 3D-растеризатор: z-буфер, перспективные UV, туман, альфа, SSAA |
| `tex.py` | процедурные блочные текстуры 16×16 и пиксельные скины персонажей |
| `rig.py` | риг персонажей (голова/тело/руки/ноги), анимации речи, ходьбы, замаха, меч |
| `scene.py` | мир: земля, лес, домик, забор с фонарями, горы, частицы, звёзды |
| `overlay.py` | субтитры, неймтеги, плашка цены, финальный логотип, цветокоррекция |
| `story.py` | режиссура: раскадровка, движение камеры, мизансцена |
| `audio.py` | озвучка (piper TTS, 3 голоса), лоу-фай музыка, SFX, сведение |
| `render.py` | покадровый рендер в 4 процесса |

## Сборка

```bash
pip install piper-tts                      # + модели ru_RU denis/dmitri/ruslan
python3 audio.py                           # -> mix.wav, timeline.json
python3 render.py                          # -> work/frames/*.png (753 кадра)
ffmpeg -framerate 24 -i work/frames/%05d.png -i mix.wav \
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k -shortest out.mp4
```

Тайминг монтажа берётся из `timeline.json`, который пишет `audio.py`, —
длительность реплик определяет длину сцен.
